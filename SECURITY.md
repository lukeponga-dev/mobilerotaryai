# Security Policy

## Supported Versions
The following table outlines which versions of RotorSense are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| >= 1.0.0 | ✅ Supported        |
| < 1.0.0  | ❌ Not Supported    |

Only actively supported versions will receive patches for security vulnerabilities.  
Users are strongly encouraged to upgrade to the latest supported release.

---

## Reporting a Vulnerability
We take security seriously and appreciate your help in keeping RotorSense safe.  

If you discover a vulnerability, please follow these steps:

1. **Report via Email**  
   Send details to: **developmentdesignsltd@gmail.com**

2. **Include Information**  
   - A clear description of the issue  
   - Steps to reproduce the vulnerability  
   - Any potential impact or severity assessment  

3. **Response Timeline**  
   - We will acknowledge receipt of your report within **72 hours**.  
   - You can expect updates on the investigation status at least once every **7 days** until resolution.  

4. **Resolution Process**  
   - If the vulnerability is accepted, we will work on a fix and release it in the next supported version update.  
   - If declined, we will provide a clear explanation of why it does not qualify as a security issue.  

---

## Commitment
- We aim to resolve critical vulnerabilities within **14 days** of confirmation.  
- Non-critical issues may be scheduled for the next planned release cycle.  
- Security patches will be documented in release notes for transparency.
